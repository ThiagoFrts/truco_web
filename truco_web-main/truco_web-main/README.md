# Truco Web — Truco Mineiro

Plataforma web para jogar Truco Mineiro contra o computador, com cadastro, login, ranking e estatísticas.
Projeto didático feito com HTML, CSS, JavaScript puro, PHP e MySQL.

## Funcionalidades
- Jogo contra o computador (3 níveis de dificuldade)
- Cadastro, login e sessão
- Ranking global
- Estatísticas e histórico do jogador

## Regras implementadas
- Baralho de 40 cartas, 3 cartas por jogador, partida até 12 pontos
- Manilhas fixas: 4♣ > 7♥ > A♠ > 7♦
- Demais cartas: 3 > 2 > A > K > J > Q > 7 > 6 > 5 > 4
- A mão vale 2 pontos e sobe para 4 (Truco), 6, 10 e 12
